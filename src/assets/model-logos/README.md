# Model-family images

`gemini.svg` is an unmodified Google Gemini product icon, fetched 2026-09-11
from Google's public asset host:
https://www.gstatic.com/lamda/images/gemini_sparkle_v002_d4735304ff6292a690345.svg

Used only to identify the model provider in the existing Gemini integration,
not as the Cover brand or an endorsement. Google's brand elements remain
Google's property. No recoloring, filters, or altered artwork.
Brand guidance: https://about.google/brand-resource-center/guidance/

Keep future provider artwork here and configure `logoSrc` / `providerName`
in the model choice data. Do not add an API model solely for displaying a logo:
the server/provider must support the model independently.

their owners. The two Seedream cards intentionally share the ByteDance mark;
the two Riverflow cards intentionally share the Sourceful mark.

# Sourceful

`sourceful.png` is a local raster copy of Sourceful's official favicon fetched
2026-09-13 from https://www.sourceful.com/favicon.ico and converted from ICO to
PNG without redrawing. It is used only as provider identification. Model
availability remains governed independently by the server allowlist and the
live OpenRouter endpoint check.
