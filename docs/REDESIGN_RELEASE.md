## Что входит

Реализация фаз foundation/shell/Create из канонического
`/srv/projects/web/AI-cover/design.md`, подготовленного через OpenDesign ElevenLabs.
Семантические токены, нейтральная светлая и тёмная темы, навигация по прежним девяти
разделам, мобильное меню, единая типографика и локальная основная кнопка создания.
Рабочая область разделена на параметры и результаты; второстепенные параметры
раскрываются по запросу. Сохранены загрузка, вставка, сцена, референсы, импорт
колоды, модели, batch, доработка и скачивание.

Приложение не блокируется отсутствием ключа генерации. Ошибка серверного
сохранения не скрывает готовое изображение. Остановка ожидания не называется
отменой операции у провайдера; поздний ответ старого запуска не меняет новый.

Это **не завершение глобального редизайна**. Внутренние интерфейсы остальных
вкладок остаются на ограниченном legacy-мосте стилей. HS-редактор сохраняет
смонтированное состояние при навигации. API, MySQL, файлы uploads, SSO, env,
серверная логика и зависимости не меняются.

Скрипт выпуска `/tmp/cover-foundation-release.mjs` проходит rehearsal на отдельном
временном каталоге (публикация и откат), затем независимое критическое ревью.
Перед реальным запуском требуется завершённое ревью текущего diff и скрипта.
Команды под блокировкой, только после проверки хешей:

```sh
sudo -n flock -n /run/lock/cover-foundation-release.lock node /tmp/cover-foundation-release.mjs deploy
sudo -n node /tmp/cover-foundation-verify.mjs
# Только если требуется откат именно этого активного выпуска:
sudo -n flock -n /run/lock/cover-foundation-release.lock node /tmp/cover-foundation-release.mjs rollback
```

Режим `rollback` проверяет, что активен именно этот выпуск, и атомарно
восстанавливает прежний index. Добавленные assets остаются: это безопасно для
открытых вкладок и не затрагивает данные. Не применять откат поверх чужого релиза.
Для последующего отката вместо временного пути используйте сохранённый
`/var/backups/cover-image/20260911-foundation-350720e/release.mjs` под тем же flock.

Commit/push не входят в эту выкладку без отдельного запроса. Не добавлять
служебный symlink `node_modules` в Git. Задача ZUL-10 остаётся открытой для
следующих этапов глобального редизайна.
